# Projektna naloga ROM
Ta repozitorij vsebuje projekt, v katerem analiziram delnico PETG (Petrol Group d.d.) za leto 2018. Ta projekt je pripravljen pri predmetu
Računalniška orodja v Matematiki 2024/5 mojega študija v 1. letniku na Fakulteti za matematiko in fiziko, Univerza v Ljubljani.

Pri projektu bom uporabljal računalniški program Wolfram Mathematica.

# Načrt projekta
1. Pridobil bom podatke iz leta 2018 o cenah delnice PETG
2. Analiziral te podatke, jih grafično prikazal in razložil
3. Naredil primerjavo s delnicama DAX in S&P500 v istem letu
4. Simuliral kupca, ki naključno kupuje in prodaja in gledal njegovo izgubo/dobiček.
